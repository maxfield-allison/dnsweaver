Apply TTL changes to existing Technitium A, AAAA and CNAME records. Changing a provider instance's TTL (`DNSWEAVER_{NAME}_TTL` / `providers[].ttl`) only affected newly created records, because the reconciler's update check delegates to the provider comparer, which only looked at companion HTTPS state. The Technitium comparer now reports TTL drift, and the existing native update rewrites the record in place.
